# MSC Co-op releases

Release builds of MSC Co-op, a co-op multiplayer mod for My Summer Car (MSCLoader).

## Install / update
1. Download `MSCMP.dll` from the [latest release](../../releases/latest).
2. Put it in your My Summer Car `Mods` folder (replace the old one). Close the game first.
3. Host and guest must run the same version.

You need your own Steam copy of My Summer Car and MSCLoader. This repo only holds the mod DLL, no game files.
